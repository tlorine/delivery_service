# ADR-0008. Деньги — целые минимальные единицы

Статус: принято · 2026-11-09

- Все суммы в БД и API — `int` в минимальных единицах (`*_minor`, копейки), `BIGINT` в PostgreSQL. Валюта — `tenant.currency` (ISO 4217, по умолчанию `RUB`), в ответах явно поле `currency`.
- Никакой арифметики на float ни на бэкенде, ни на фронте. Форматирование — `Intl.NumberFormat('ru-RU', {style:'currency', currency})` от `minor / 100` только для отображения (общая функция в `packages/core`).
- Скидки в процентах (после MVP) округляются целочисленно в пользу покупателя, правило фиксируется в `pricing`.
- food-schema хранит `price: number` в рублях; адаптер делит на 100 только для отображения и никогда не отправляет такие значения на сервер.
