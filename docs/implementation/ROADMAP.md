# Дорожная карта

Принцип: один работающий сквозной сценарий важнее десятка незавершённых модулей. Этап закрыт только после прогона тестов/сборок.

| Этап | Содержание | Критерий готовности |
|---|---|---|
| 0. Аудит ✅ | Изучение NextOrders, базовый прогон тестов | `docs/audit/00-nextorders-audit.md` |
| 1. Архитектура ✅ | Документы `docs/architecture/*`, ADR 0001–0009 | Документы согласованы с кодом |
| 2. Backend foundation ✅ | FastAPI, конфиг, PostgreSQL, Alembic, Dishka, ошибки RFC 9457, tenant resolution, RLS, логи, health, тестовый контур с реальной PostgreSQL | Тесты проходят на PostgreSQL; миграции up/down |
| 3. Вертикальный сценарий (backend) ✅ | Каталог с модификаторами, корзина, расчёт цен, зоны доставки, расписание, оформление с идемпотентностью, FSM заказа, аудит, outbox, Telegram-уведомление кафе, админ-API заказов, сид демо-кафе | Тесты: цены, FSM, изоляция, конкурентность, идемпотентность, API |
| 3b. Вертикальный сценарий (web) ✅ | `packages/api-client`, перевод сторов `core`/`web-app` на API, модификаторы в карточке товара, экран статуса заказа, русский по умолчанию, брендинг тенанта | E2E полного заказа на собранном приложении |
| 4. Telegram Mini App ✅ | Платформенный адаптер, `/v1/telegram/session`, webhook бота, привязка чата уведомлений | Проверка запуском через реального бота |
| 5. Админка ✅ | `apps/admin`: заказы (лента + звук), меню, стоп-лист, расписание, зоны доставки, настройки, сотрудники, аналитика | E2E: сотрудник подтверждает заказ |
| 6. Mobile | `apps/mobile` (Capacitor) по ADR-0005 | Сборка и проверка на реальных Android/iOS |
| 7. Стабилизация | Полный прогон, CI, бэкапы, мониторинг, документация | STATUS.md актуален |

После MVP: онлайн-оплата (ЮKassa/СБП) + фискализация, Яндекс Доставка, серверное геокодирование, SMS-вход, промокоды, push в мобильном приложении.
